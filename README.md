# Практическая работа №5

## Подбор порога классификации с учётом цены ошибок

### Цель работы

Обучить модель бинарной классификации, получить вероятностные предсказания с помощью `predict_proba()`, построить ROC- и PR-кривые, вычислить AUC и подобрать оптимальный порог классификации с учётом различной стоимости ошибок.

### Датасет

Используется датасет **Breast Cancer Wisconsin (Diagnostic)** из UCI Machine Learning Repository.

Характеристики датасета:

* 569 объектов;
* 30 числовых признаков;
* 2 класса;
* 212 злокачественных объектов;
* 357 доброкачественных объектов.

Целевая переменная преобразована следующим образом:

* `0` — доброкачественная опухоль;
* `1` — злокачественная опухоль.

Источник:

UCI Machine Learning Repository — Breast Cancer Wisconsin (Diagnostic).

### Используемая модель

Для классификации используется логистическая регрессия (`LogisticRegression`).

Перед обучением признаки стандартизируются с помощью `StandardScaler`.

Данные разделены на:

* 80% — обучающая выборка;
* 20% — тестовая выборка.

При разделении используется стратификация классов и `random_state=42`.

### Вероятностные предсказания

Вместо бинарных предсказаний используются вероятности принадлежности объекта к положительному классу:

```python
model.predict_proba(X_test_scaled)[:, 1]
```

Положительный класс — злокачественная опухоль.

### ROC-кривая и ROC-AUC

ROC-кривая построена для оценки качества модели при различных порогах классификации.

Вычислено значение ROC-AUC.

### PR-кривая и PR-AUC

Также построена Precision-Recall кривая и вычислено значение PR-AUC.

PR-кривая позволяет оценить соотношение Precision и Recall при изменении порога классификации.

### Цена ошибок

В данной задаче ложноотрицательная ошибка считается более дорогой, чем ложноположительная.

Ложноотрицательная ошибка означает, что злокачественная опухоль была классифицирована как доброкачественная.

Поэтому основной метрикой при выборе порога является Recall.

### Подбор порога

Стандартный порог классификации равен:

```text
0.50
```

Для подбора нового порога были рассмотрены различные значения порога.

Выбран порог, при котором:

* Recall не ниже 0.95;
* среди подходящих значений достигается максимальный F1-score.

Итоговое значение порога необходимо взять из результата выполнения ноутбука.

### Сравнение

В работе сравниваются метрики модели при:

1. стандартном пороге `0.50`;
2. выбранном пороге.

Сравниваются:

* Accuracy;
* Precision;
* Recall;
* F1-score;
* количество TP, TN, FP и FN.

### Вывод

Изменение порога классификации позволяет изменить баланс между Precision и Recall.

Поскольку в данной задаче ложноотрицательные ошибки являются более критичными, предпочтение отдаётся более высокому Recall. Снижение порога относительно 0.50 позволяет обнаруживать больше злокачественных случаев, однако может привести к увеличению количества ложноположительных результатов.

Поэтому выбранный порог представляет собой компромисс между обнаружением положительных случаев и количеством ложных срабатываний.
